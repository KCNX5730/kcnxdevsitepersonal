About KCNX WEB OS

Prototype Version: KCNX Web OS is a lightweight, browser-based operating system prototype. It is designed as a demo for the future of web operating systems, focusing on lightweight software contents that can run entirely within your browser without the need for heavy installations.

Advantages

  • Extremely lightweight and fast.
  • Accessible from any device with a modern browser.
  • Zero installation required (runs directly from an HTML file).
  • Cross-platform compatibility (Windows, macOS, Linux, Android, iOS).

Limitations

  • As a prototype, it is constrained by browser sandboxing.
  • Local storage constraints (IndexedDB limits).
  • Lacks deep hardware integration (e.g., direct low-level file system access).
  • Performance depends on the host browser's JavaScript engine.

KCNX WebOS Privacy Policy

Last Updated: 2026

Your privacy is of the utmost importance. This Privacy Policy outlines how KCNX Web OS handles your data.

1. Data Collection: KCNX Web OS is a purely client-side application. When you download and run the OS file, all data (such as files you upload, notes you write, and settings you change) is stored locally on your device using browser technologies like IndexedDB and localStorage. We do not collect, transmit, or store any of your personal data on external servers.

2. Cookies & Tracking: We do not use tracking cookies or analytics on the OS application itself. Local storage is strictly used for functionality (e.g., remembering your wallpaper choice).

3. Third-Party Integrations: The OS includes optional iframe integrations (e.g., Spotify embeds, Google Drive). If you choose to use these features, those third-party services may collect data according to their own privacy policies.

4. Security: Since all data is stored locally in your browser's sandbox, the security of your data depends on your device's security. We recommend using a secure, up-to-date web browser.

By downloading and using KCNX Web OS, you acknowledge and agree to these terms.
